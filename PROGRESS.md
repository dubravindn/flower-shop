# Ход работ

## Итерация 1 — дизайн-система и главная страница

**Статус:** главная страница готова, проверки пройдены. Ожидает визуальной приёмки.

### Что сделано

| Этап | Результат |
| --- | --- |
| Диагностика | Каркас Next 16.3.1 / React 19.2.8 / TS / Tailwind 4 на месте, `legacy/` цел |
| Зависимости | `zod` (прод), `sharp` (dev, обработка изображений) |
| Дизайн-система | Токены палитры, Prata + Manrope, сетка, кнопки, поля, бейджи, состояния |
| Данные | `company.ts`, `navigation.ts`, `founders.ts`, `src/content`, типы, `.env.example` |
| Владельцы | `FoundersSection`, пять пропорций, заглушки вместо непригодного исходника |
| Главная | 14 блоков от служебной строки до подвала |
| Проверки | lint ✅, typecheck ✅, build ✅ |

### Проверки

```
npm run lint     ✅ без замечаний
npx tsc --noEmit ✅ без ошибок
npm run build    ✅ / , /brand-preview , /_not-found — статика
```

Дополнительно проверено, что фирменные классы и токены реально попали
в собранный CSS (`--color-red-brand`, `container-page`, `rule-foil`),
а шрифты скачаны локально — 10 файлов `.woff2` в сборке.

### Решения, которые стоит знать

1. **Переход на Next.js обоснован технически.** Статический `index.html`
   не даёт корзины, серверных экшенов и интеграции с «МойСклад».
   Прежний сайт целиком сохранён в `legacy/`.

2. **Цены не заполнены.** Компания их не передавала, придумывать нельзя.
   `price: null` выводится как «Цена уточняется», кнопка — «Узнать цену».
   Правится в `src/content/catalog.ts`.

3. **Отзывов нет.** Массив в `src/content/reviews.ts` пуст, блок показывает
   честное пустое состояние вместо выдуманных имён и оценок.

4. **Фотография владельцев не подошла.** Подробности — в
   `founders-source/README.md`. На сайте стоят фирменные заглушки.
