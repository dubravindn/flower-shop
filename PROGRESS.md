### Не сделано (следующие итерации)

- Каталог `/catalog`, категории, карточка товара
- Корзина и checkout
- Оптовый раздел и адаптер «МойСклад»
- Корпоративные, доставка, контакты, о компании, уход, юридические
- Аналитика, sitemap, robots
- Тесты (Vitest, Playwright)

### Решения, которые стоит знать

1. **Переход на Next.js обоснован технически.** Статический `index.html`
   не даёт корзины, серверных экшенов и интеграции с «МойСклад».
   Прежний сайт целиком сохранён в `legacy/`.

2. **Цены не заполнены.** Компания их не передавала, придумывать нельзя.
   `price: null` выводится как «Цена уточняется», кнопка — «Узнать цену».
   Правится в `src/content/catalog.ts`.

3. **Отзывов нет.** Массив в `src/content/reviews.ts` пуст, блок показывает
   честное пустое состояние вместо выдуманных имён и оценок.

4. **Фотография владельцев не подошла.** Подробности — в
   `founders-source/README.md`. На сайте стоят фирменные заглушки.

## Итерация 2 — P0: публикация внутренних страниц

**Статус:** выполнено. Внутренних 404 не осталось.

### Что сделано

Проведён read-only аудит, результат — `AUDIT_BEFORE_CHANGES.md`.

Создана 21 страница вместо двух:

| Раздел | Адреса |
| --- | --- |
| Каталог | `/catalog`, `/catalog/[category]` (6), `/product/[slug]` (11) |
| Заказ | `/cart`, `/checkout`, `/order/success` |
| Опт | `/wholesale`, `/wholesale/catalog` |
| Компания | `/about`, `/contacts`, `/delivery`, `/care`, `/corporate` |
| Клиентская база | `/reminders`, `/unsubscribe` |
| Юридические | `/privacy`, `/consent`, `/offer` |
| Служебные | `/sitemap.xml`, `/robots.txt`, 404 |

Убраны иконки поиска, избранного и корзины из шапки: они вели в пустоту.
В мобильной панели корзина заменена на магазины.

Добавлен `scripts/check-links.mjs` — обходит статическую выгрузку и падает,
если найдена битая внутренняя ссылка. Подключён в CI перед публикацией.

### Проверки

```
npm run lint         ✅
npm run typecheck    ✅
npm run build:pages  ✅ 37 страниц
npm run check:links  ✅ 946 ссылок, битых нет
```

### Осознанные ограничения

1. **Корзина и оформление не работают.** Складывать в корзину товары без цен
   бессмысленно, поэтому страницы существуют, но честно объясняют, что заказ
   принимает флорист. Механика — этап P2 вместе с ценами.
2. **Оптовые остатки не выводятся.** «МойСклад» не подключён, а показывать
   выдуманные позиции нельзя: оптовый клиент примет их за настоящие.
3. **Форма важных дат не принимает данные.** Хранить телефоны можно только
   на сервере с согласиями — этап P3. Пока дату принимает менеджер.
4. **Юридические страницы — шаблоны.** Реквизиты, ИНН и ОГРН не переданы,
   документы требуют проверки юристом. Это помечено на самих страницах.
