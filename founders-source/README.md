# Технические кадрирования фотографии владельцев

Здесь лежат кадрирования из `IMG_6902.PNG` в пяти пропорциях, требуемых ТЗ:
16:9, 4:5, 3:2, 1:1 и 1200×630. Метаданные и геометки удалены.

**Папка намеренно вне `public/`** — файлы не раздаются по HTTP и не попадают в сборку.

Причины, по которым исходник не подходит для публикации:

1. Надпись на футболке читается полностью и содержит нецензурный текст.
2. Съёмка в ночном клубе: тёмный интерьер, клубный свет — противоречит
   премиальному архитектурному стилю из ТЗ.
3. В кадре посторонние люди, не дававшие согласия на коммерческое использование.
4. Внизу исходника вшит рекламный баннер стороннего мероприятия
   (кадрированием убран, но исходник остаётся чужим материалом).
5. Ширина исходника 1320 px — мало для баннера 1920 px.

## Как подключить чистую съёмку

1. Положить файлы в `public/images/founders/` с именами
   `founders-16x9.jpg`, `founders-4x5.jpg`, `founders-3x2.jpg`,
   `founders-1x1.jpg`, `founders-og.jpg`.
2. В `src/config/founders.ts` поставить `useRealPhotos: true`.

Больше ничего менять не нужно — компонент `FoundersSection` подхватит их сам.
